# Sellam Store — Frontend

Interface React pour la gestion de boutique.

## Stack
- React + Vite
- Tailwind CSS
- axios, react-router-dom

## Lancer le projet
1. `npm install`
2. `npm run dev`
3. App disponible sur `http://localhost:5173`
